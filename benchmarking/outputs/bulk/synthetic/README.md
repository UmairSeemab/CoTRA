# Synthetic bulk benchmark outputs

Contains:
- S2 summary table
- reviewed summary CSV
- all five measured run-level outputs for each DESeq2/edgeR dataset size
- step-level timing CSVs
- GNU `/usr/bin/time -v` resource files
- session information files where recorded

Measured sizes: 6, 12, 24, 48, and 96 samples with 20,000 genes.

Preliminary viability runs are stored separately under
`Benchmarking_outputs/preliminary_viability_runs/` and were excluded from
reported statistics.
