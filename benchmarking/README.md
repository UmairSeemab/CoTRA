# CoTRA benchmarking resources

This package is structured for direct inclusion in the CoTRA GitHub repository.

Recommended destination:

```text
CoTRA/
└── benchmarking/
    ├── code/
    └── outputs/
```

`code/` contains the final computational performance scripts.
`outputs/` contains the machine-readable S1-S6 summaries, raw measured run files,
figure source data, and preliminary viability runs.
