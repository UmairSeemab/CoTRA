# Real bulk RNA-seq benchmark code

This folder contains the final scripts used for computational performance
benchmarking of the real retinal bulk RNA-seq dataset.

## Dataset
- 55,291 genes
- 12 samples
- 4 WT
- 8 rd10
- rd10 versus WT comparison

## Files
- `benchmark_bulk_real.R`
- `run_bulk_real_linux.sh`
- `summarize_bulk_real.R`

The corresponding machine-readable outputs are in:
`Benchmarking_outputs/bulk/real/`.
